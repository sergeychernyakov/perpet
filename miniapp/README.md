# Мини-приложение PERPET для VK

Статическая страница без сборки: VK Bridge подключается с CDN, данные берутся
из API основного сайта (`/api/v1`). Приложение VK: **54774377**.

## Экраны

| Вкладка | Что умеет |
| --- | --- |
| Объявления | каталог, фильтр по виду питомца, поиск, «Показать ещё», отклик |
| Статьи | список и чтение статьи |
| Профиль | данные хозяина и питомца, свои объявления, создание и удаление черновика |
| Поддержка | каналы связи, частые вопросы, форма обращения |

## Локальная отладка

```bash
npm start                       # раздаёт папку на http://localhost:5173
```

Откройте с адресом своего API и подставленными параметрами запуска:

```
http://localhost:5173/index.html?api=http://localhost:3000&vk_user_id=501&vk_app_id=54774377
```

Без `VK_APP_SECRET` сервер в разработке подпись не проверяет, поэтому хватает
`vk_user_id`. В production без верной подписи API отвечает 401.

## Выкладка на хостинг VK

```bash
npx @vkontakte/vk-miniapps-deploy login   # один раз: вход в аккаунт VK
npm run deploy                            # сборка в build/ и заливка
```

`vk-hosting-config.json` уже указывает на приложение 54774377 и на `build/`.
После заливки адрес появится в настройках приложения на dev.vk.com, а
`npm run deploy -- --production` переведёт загруженную версию в боевую.

## Что нужно, чтобы заработало внутри VK

1. У основного сайта должен быть **HTTPS на своём домене** — VK не пускает
   ни `http://`, ни адрес по IP. Значит, сначала A-запись `perpet` и сертификат
   (см. `../DEPLOY.md`).
2. Домен мини-приложения должен быть в `CORS_ORIGINS` на сервере — сейчас там
   разрешены `https://*.vk-apps.com` и `https://vk.com`.
3. `VK_APP_SECRET` на сервере — уже прописан.
