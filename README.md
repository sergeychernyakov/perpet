# PERPET

Сервис передержки животных: объявления о поиске временных хозяев, статьи, профиль и поддержка.
Веб-приложение на Ruby on Rails 8 с базой SQLite, свёрстанное по макету из Figma.

Дальше к нему добавится мини-приложение VK, которое работает с этим сервисом по API.

## Стек

- Ruby 3.3, Rails 8.1, SQLite
- Propshaft, importmap, Turbo и Stimulus
- Свой CSS по токенам макета, без UI-фреймворков
- Minitest, RuboCop (rails-omakase), Brakeman

## Запуск

```bash
bundle install
bin/rails db:prepare
bin/rails db:seed
bin/rails server
```

Приложение поднимется на http://localhost:3000 уже с данными: 16 объявлений, 15 статей,
6 вопросов в FAQ, 3 канала поддержки и демонстрационный профиль «Анна Петрова».

Тесты и проверки:

```bash
bin/rails test     # 23 теста
bin/rubocop        # стиль
bin/brakeman       # безопасность
```

## Что уже работает

| Страница | Адрес | Что внутри |
| --- | --- | --- |
| Главная | `/` | Обложка, преимущества, диаграмма, промо-карточки, блок «ВАЖНО» |
| Знакомство с нами | `/about` | Проблема, преимущества, статистика, шаги передержки |
| Объявления | `/ads` | Поиск, фильтры по виду питомца, карточки, постраничная навигация |
| Статьи | `/articles` | Карточки статей с тегами и пагинацией |
| Профиль | `/profile` | Данные пользователя, свои объявления, создание черновика |
| Поддержка | `/support` | Каналы связи, FAQ, форма обращения |

Сквозные элементы: шапка с мобильным меню, подвал с контактами и модальное окно заявки
(«присоединиться» и «Откликнуться» в объявлениях). Формы заявки и обращения отправляются
через Turbo Streams — страница не перезагружается.

## Данные

Сиды в `db/seeds.rb` наполняют сервис данными из макета: объявления по городам и видам питомцев,
статьи с тегами и временем чтения, вопросы поддержки, каналы связи и профиль с двумя объявлениями.
`bin/rails db:seed` пересоздаёт данные с нуля.

## Исходное ТЗ

> Требования: Полностью работоспособный продукт, который работает и качественно отображается на любом современном устройстве в вебе. Мини-приложение в VK, которое работает по API с основным продуктом.
>
> Полностью законченное веб приложение на Ruby On Rails. Полностью законченное мини-приложение в VK.
>
> Сервис должен быть наполнен данными через сиды. Должна быть админка, бд sqlite и адаптивная верстка. К тому что есть еще будет добавлена страница со списком статьей, соответственно две страницы самих статей, профиль, и две страницы объявлений

## Заметки по работе

- В текстах макета исправлена опечатка: «обьявление» → «объявление».
- Гем `json` зафиксирован на версии 2.x: в 3.0 изменилась сигнатура `JSON.parse`,
  из-за чего Rails 8.1 падает при чтении сессии.
- Блоки появляются по прокрутке (`animation-timeline: view()`), соседние карточки — каскадом.
  Браузеры без поддержки scroll-анимаций просто показывают блоки сразу.
- Фото питомца из Claude Design скачивалось обрезанным (лимит 256 КБ), поэтому взято
  из исходного файла Figma и сохранено в JPEG.
